# School Portal (Blazor)

Minimal and responsive Blazor school portal with two user roles:

- **Administrator**: create questionnaires and class schedules.
- **Student**: view personal calendar, choose class schedules, and submit questionnaire answers.

## Tech stack

- Blazor Web App (interactive server components)
- .NET 9 (`net9.0` target)

## Run

```bash
dotnet restore
dotnet run
```

Then open `https://localhost:5001` or the URL shown in terminal.
